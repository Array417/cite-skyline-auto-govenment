# AutoGovernment

Cities: Skylines II 虛擬政府 Mod 專案。玩家以國家元首身分輸入施政方向，透過「提出建議」或「強制命令」影響政府決策與城市。

**目前處於開發前驗證，尚未提供可玩成品或安裝包。** 倉庫中的 C# 程式仍是載入／卸載模板；文件描述的是完整產品要求，不能視為已實作功能。

預定功能包括共享本地輕量 LLM 的政府 agents、自主買地／劃區／道路與橋隧建設，以及選舉、議會、司法、股票、社會抗議和獨裁玩法。優先驗證以獨立 Mod 擴充 Presidente；已讀回部分公開系統，但政策寫入、城市效果、施工及存檔相容性仍待實測，尚未形成正式整合承諾。

## 建置狀態

此專案使用 Cities: Skylines II 官方 Mod 工具鏈，目標為 `net48`／C# 9；已安裝的 .NET SDK 8 不代表遊戲 Mod 使用 `net8.0`。建置需要本機遊戲與工具鏈所提供的組件及 `CSII_TOOLPATH` 設定，詳見開發指引。

獨立實驗已通過編譯、官方 postprocess、遊戲載入及 UI／C# 雙向通訊；正式產品尚未完成。發佈設定仍是模板，不能直接作為正式發佈配置。
